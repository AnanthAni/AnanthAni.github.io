Privacy policy: Morning Briefing

Last updated 10 November 2026.

Morning Briefing is a personal tool used only by its owner. With the owner's consent it accesses the owner's Google Calendar to read events and create events.

  • Calendar data is processed only on the owner's own computer and is not sold, shared or transferred to any third party.
  • The OAuth token is stored locally on that computer and can be revoked at any time at myaccount.google.com/permissions.
  • No data from other Google users is collected.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
